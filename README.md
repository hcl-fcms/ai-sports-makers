# AI 運動創客隊｜第 4 堂：做玩家偵探

郭怡雅神父紀念學校（2026-27）「AI 運動創客隊」課堂簡報。對象為小四至小六，15 至 20 人，分四組，每堂 70 分鐘。

本堂承接第 1 至 3 堂的「先試、先判斷、先講清楚」，重點不是教 AI 工具，而是訓練學生用可觀察的試玩證據，分辨「我不喜歡」與「玩家在哪一步遇到問題」。

## 七頁結構

1. 封面：第 4 堂｜做玩家偵探｜找出真正的問題
2. 今日你要做甚麼：重玩閃避遊戲、寫下預測、輪流做玩家與觀察員、用證據講清楚問題
3. 先估，再試：每人先寫「我估玩家會喺邊一步卡住」
4. 觀察：只描述行為，唔貼標籤（反面與正面寫法對照）
5. 同一個問題，可能唔止一個原因（三種可能原因）
6. 小組任務：玩家觀察表（步驟／預期／實際／待核實），核心完成四欄，挑戰提出第二個可能原因
7. 離堂前一句：我看到＿＿，可能因為＿＿，下次我會試＿＿；遷移題：換成小一玩家會先檢查甚麼

## 教學設計要點

- **學教評一致**：本堂教的關鍵方法是「預測 → 觀察 → 待核實」，即堂證據是每人一句觀察句加每組一張觀察表，不設評分或排名。
- **Thinking Gate**：WHY＝說明選題或規則的證據與理由；HOW＝實際觀察、填寫四欄表；TRANSFER＝換成小一或少遊戲經驗玩家時，自行調整設計。
- **私隱底線**：觀察紀錄不記姓名、個人成績或身體表現；學生作品使用虛構角色；教師主控 Gemini 帳戶，不把任何玩家觀察或學生資料輸入 AI。
- **分層**：需支援的學生使用「我看到＿＿」句框；進階學生須提出第二個可能原因。
- **沒有裝置時**：以教師操作的遊戲片段或紙本情境觀察，並明確標示為「模擬」，不可當作真實玩家測試。
